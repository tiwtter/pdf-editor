# PDF Editor

โปรแกรมแก้ไฟล์ PDF แบบง่าย เขียนด้วย Python (tkinter + PyMuPDF) รองรับภาษาไทย

- **แก้ข้อความทีละชั้น** — คลิกที่ข้อความ ถ้ามีข้อความซ้อนกันจะแสดงทุกชั้นให้เลือกแก้ทีละชั้น ชั้นอื่นไม่เสีย
- **ใช้ฟอนต์เดิม** — หาฟอนต์เดิมของข้อความในเครื่องให้อัตโนมัติ (ถ้าไม่มีจะลองใช้ฟอนต์ที่ฝังใน PDF) วางตรงตำแหน่ง ขนาด และสีเดิม
- **แก้เส้นตาราง** — ย้าย / เปลี่ยนความหนาและสี / ลบ / เพิ่มเส้น เส้นที่มาชนจะยืดหดตาม
- ย้อนกลับได้ 20 ครั้ง (Ctrl+Z / Cmd+Z) และบันทึกเป็นไฟล์ใหม่ ไฟล์ต้นฉบับไม่ถูกแก้

## ติดตั้งและเปิดโปรแกรม

ต้องมี **Python 3.10 ขึ้นไป** — ดาวน์โหลดได้ที่ <https://www.python.org/downloads/>
(Windows: ตอนติดตั้งให้ติ๊ก **Add python.exe to PATH**)

ดาวน์โหลดโค้ด: ปุ่ม **Code → Download ZIP** บนหน้านี้ แล้วแตกไฟล์ หรือใช้ git:

```bash
git clone https://github.com/tiwtter/pdf-editor.git
```

### วิธีง่าย (แนะนำ)
| ระบบ | วิธีเปิด |
|---|---|
| Windows | ดับเบิลคลิก `run.bat` |
| macOS | ดับเบิลคลิก `run.command` (ครั้งแรกถ้าเปิดไม่ได้: คลิกขวา → Open) |
| Linux | `./run.command` |

ครั้งแรกจะสร้างโฟลเดอร์ `.venv` และติดตั้ง PyMuPDF ให้เอง (ต้องต่ออินเทอร์เน็ต) ครั้งต่อไปเปิดได้ทันที

### วิธีติดตั้งเอง
```bash
python3 -m pip install -r requirements.txt
python3 pdf_editor.py [ไฟล์.pdf]
```
(Windows ใช้ `py` แทน `python3`)

**Linux** ต้องติดตั้ง tkinter เพิ่ม: `sudo apt install python3-tk`
**macOS ที่ใช้ Python จาก Homebrew** : `brew install python-tk`

## ฟอนต์ภาษาไทย

โปรแกรมค้นหาฟอนต์ในโฟลเดอร์ฟอนต์ของระบบ และฟอนต์ที่มากับ Microsoft Office
ถ้าเครื่องไม่มีฟอนต์เดิมของเอกสาร จะใช้ฟอนต์สำรอง (TH Sarabun New / Leelawadee UI / Tahoma / Noto Sans Thai)
และแสดงคำเตือนใต้ปุ่มเลือกฟอนต์ — ติดตั้งฟอนต์นั้นลงเครื่องแล้วผลจะเหมือนต้นฉบับ

## ข้อจำกัด

- แก้ได้เฉพาะ PDF ที่มีข้อความ/ลายเส้นจริง ไฟล์สแกนหรือตารางที่เป็นรูปภาพแก้ไม่ได้ (เพิ่มเส้นใหม่ได้)
- ย้ายเส้นตารางแล้ว ข้อความในช่องไม่ขยับตาม
- เลือกได้เฉพาะเส้นแนวนอน/แนวตั้ง
- หน้าที่ถูกหมุน ข้อความที่แก้จะถูกวางในกรอบของข้อความเดิม ตำแหน่งอาจไม่ตรงเป๊ะ
